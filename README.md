# Dark Mode Professional Resume

A high-quality, dark-themed personal resume website built with Next.js, Tailwind CSS, and Framer Motion.

## Features

- 🌙 **Dark Mode**: Premium dark aesthetic.
- 🌐 **i18n**: Supports Traditional Chinese and English.
- 📱 **Responsive**: Optimized for all devices.
- ⚡ **Fast**: Built with Next.js 14+ App Router.

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

### Build

```bash
pnpm build
```

## Project Structure

- `src/app`: Next.js App Router pages and layouts.
- `src/components`: Reusable UI components.
- `src/context`: Language context for i18n.
- `public`: Static assets (photos, icons).
- `zh.json` / `en.json`: Resume content in different languages.
